Что умеет

  • Пайплайн фиксирован: новый → в работе → на проверке → выполнен → закрыт, плюс отмена
  • Каждый переход пишет историю с автором и основанием, заинтересованных уведомляет
  • Назначение проверяет роль: менеджера исполнителем не назначить (422), несуществующего — отклоняет (404)
  • Ошибки не молчат: PATCH с полем executorId возвращает 400 и указывает правильную ручку
  • Просрочка считается по сроку этапа, а не заказа целиком
  • Исполнитель видит только свои заказы и не видит отчёты
  • Отчёты: воронка, среднее время этапа, загрузка исполнителей, просрочка, сводка одним ответом

Как запустить

Нужен только Node.js 20+ — зависимостей нет, сборки нет.

node server.js — сервис поднимется и создаст демо-данные при первом запуске.

node --test test/app.test.mjs — прогон тестов.

Демо-доступ: anna@tenderpulse.ru (администратор), maxim@tenderpulse.ru (менеджер), ilya@tenderpulse.ru (исполнитель); пароль — в консоли сервера, целиком — GET /api/demo
